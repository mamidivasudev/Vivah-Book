# VivahBook

Wedding gift register for Android. Write down who gave what at a wedding or function, and who you gave to.
Later, look up a name to see what to give back.

- Works fully offline. Everything stays on the phone. No accounts, no ads, no internet permission.
- Functions (yours = gifts received, or someone else's = gifts given), quick entry with customary amounts
  (101, 201, 501, 1001...), People tab, search, copy as text/CSV, copy/paste backup and restore, text size setting.

Built with Flutter. Run the tests with `flutter test`; build with `flutter build apk --release`.
Release signing uses `android/key.properties` and `android/keys/` (kept out of the repository).
